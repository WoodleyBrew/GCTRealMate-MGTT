# Explanation's
#
# Wind/Rain Sim Line
#	This code allows the player to see the effects of wind and rain with the simulation line by holding the Z button. 
#	This stacks with the Hook/Slice and Putter Sim Line codes. 	
#
# Hook/Slice Simulation Line
#	This code allows the player to see the effects of hook and slice with the simulation line by holding the Y button and pressing either Left or Right on the DPad. 
#	This stacks with the Wind/Rain Sim Line code. 	
#
# Putter Simulation Line
#	This code allows the player to see the effects of hook and slice with the simulation line by holding the Y button and pressing either Left or Right on the DPad. 
#	This stacks with the Wind/Rain Sim Line code.
#
# Sim Line Visible During Swing
#	This code dynamically updates and displays the Sim Line while taking the shot.
#
# Wind Editor Z Button + C-Stick
#	This code allows users to edit wind speed and direction while playing. Works in combination with Sim line codes. 
#	While holding Z, Left and right on C-stick changes wind direction, Up and down changes wind speed.
#
# SingDoubs Practice 
#	This code allows one player to control two characters in doubles stroke play mode. 
#	The game will automatically give the second “team” the maximum number of strokes so the player can practice the SingDoubs format uninterrupted.
