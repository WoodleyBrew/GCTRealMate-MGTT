##################################################
# Explanation's
#
# RNG% Range
# 	All Lies are set to experience the same range of RNG+-%
# 	2nd line, last digits control RNG range. Current code example is set to 0%	
#
# All Fast Fairway
#	This code makes all collisions in the game become Fast Fairway, This includes rocks, trees, water, bunkers, etc. 
#
# Putter Simulation Line
#	This code will play a thwomp sound when the landing spot is hovering over the “crater red zone.” 
#	The crater red zone is an area that is roughly 250 yards from the selected tee box, (and a second area roughly 70 yards from the green on Par 5s) that has an 
#	increased chance of bad lies due to the game designating those areas as common landing areas.
#
# All Fairway is Hazard
#	This code makes landing on fairway or fast fairway a hazard. 
#	The golfer will incur a one stroke penalty and be dropped in the nearest spot closest to where the ball entered the fairway,
#
# Use JP Lies in NA Version
#	JP lies have no crater on fairway
#
# Fairway Lie %
#	This code allows the user to customize  fairway lie percentages.
#	Every 2 lines of code corresponds to each of the main 6 courses in order (1st line is standard lie%, 2nd is the ‘red ring’ lie%)
#	The right column can be edited to match desired lie chances for standard fairway and ‘red ring’ fairway. 
#	The percents are hexadecimal value, every 2 values correspond to:
#	Clean fairway > Dirt fairway > Muddy fairway > Crater
