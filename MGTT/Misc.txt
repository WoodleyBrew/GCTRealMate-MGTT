##################################################
# Explanation's
#
# Memory Card Skip
#	Skips the memory card prompt on the title screen. Will also cause the game to not be able to save. 	
#
# Disable Boo Messagse
#	This code disables the Boo messages that get displayed when the gameplay is idled during a round. 	
#
# Disable Run Line & Stopping Point in Training Mode
#	This code removes the red simulation line representing the run line and stopping point that is only seen in training mode.
#
# Access Unused Driving Range Hole
#	This code replaces Lakitu Valley’s first hole with the unused driving range hole.
#
# Access Side Games Approach Green
#	his code replaces Lakitu Valley’s first hole with the approach green seen in the side games.
#
# Hide GUI
#	This code allows the user to hide the GUI by pressing the Y button.	
#
# Night Mode
#	This code overlays the background with the PCG 18 starry night sky + decreased lighting on most holes.
#
# Fireworks
#	This code overlays the background with the PCG 18 fireworks effect. Can be combined with Night Mode.
#
# Scorecard Animation
# 	Change last number, 0-5 for different animations
# 	5 = Screen wipe
#	4 = Card break apart
#	3 = Card melt
#	2 = bad
#	1 = bad
#	0 = Split & shrink
